# The Excuse That Almost Works

The one line a gamer texts the boss to skip work during GTA 6 launch week.

The excuse is boring on purpose: stuck at the council office because they lost the paperwork again, third visit this week. No wild story, no sudden fever, no dead grandmother — just the kind of dull bureaucratic misery a tired manager has heard before and would almost believe.

`main.py` writes that single line to `/output/entry.txt`.
